# Instrucciones del proyecto

## Pull requests

- Los pull requests creados desde la cuenta de negasva siempre se fusionan a `main` con auto merge.
- Después de crear el PR, activa el auto merge (squash) para que se fusione solo cuando los checks pasen.
- Si el auto merge no está disponible en el repositorio, avisa en la respuesta en vez de omitirlo.
